# Football Imperialism

A browser game for the 36 teams of the 2026/27 Champions League league phase.

1. **Spin the wheel** picks the attacking team (only teams that still own land are on it).
2. **Spin the arrow** spins around that team's logo and picks the neighbour it attacks.
3. **Show the match** puts the two teams side by side. Play it in FC27, then pick the winner. The winner takes all of the loser's blocks.

The game saves in your browser, so you can close the tab between matches.

## Logos

All 36 logos are in `logos/`, named after the team id. Replace a file there to change a logo (`.png`, `.svg` or `.webp`).
